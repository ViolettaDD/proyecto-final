# USFQ Reserva COCOA

Una página web, pensada primero para el celular, para que los estudiantes de la USFQ reserven equipos y espacios del COCOA en una sola solicitud, y para que los administradores las aprueben y manejen el inventario.

Es nuestro proyecto final de Web 3 en la USFQ (noviembre y diciembre de 2026).
